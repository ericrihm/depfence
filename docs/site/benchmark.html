Methodology

  • Full detection (✓): The tool has a dedicated, documented feature or scanner for this attack class and detects it by default or via a standard flag.
  • Partial (◐): The tool covers a subset of the attack class (e.g., MCP-only prompt injection but not dependency source), or requires a paid tier / third-party plugin.
  • Not supported (—): No documented capability. The tool may detect adjacent issues (e.g., CVEs in ML libraries) but not the specific attack class.
  • Comparison based on publicly documented features and official tool documentation as of June 2026.
  • Traditional SCA strengths (CVE matching, license compliance, SBOM generation) are not in scope — all tools except depfence have mature capabilities there. This benchmark focuses exclusively on AI-specific threat detection.

The AI Security Gap

Traditional software composition analysis (SCA) tools were built for a world where threats came through known CVEs, license violations, and dependency confusion. They excel at matching package versions against advisory databases. But the rise of AI coding assistants, MCP servers, and ML model supply chains has created entirely new attack surfaces that these tools were never designed to address.

What changed

Three shifts created the gap:

CRITICAL AI agents read dependency source code

When an AI coding assistant opens a project, it reads comments, docstrings, and string literals from installed packages. The jqwik 1.10.0 attack proved this isn't theoretical: a maintainer embedded adversarial instructions in a Java library that hijacked AI assistants reading the code. Traditional scanners don't inspect dependency source for natural-language payloads — they check version numbers against CVE databases.

CRITICAL LLMs hallucinate package names that attackers register

Socket.dev research found that 20% of AI-recommended packages don't exist — 205,000 unique hallucinated names across 576,000 code samples. Attackers register these names on npm and PyPI with malicious payloads. This "slopsquatting" attack bypasses CVE-based scanning entirely because the malicious package has no advisories: it was just created.

NOVEL Malware now targets the scanner itself

The Gaslight macOS malware (June 2026, DPRK-linked) embeds 38 fake "system" messages in a Rust binary — fabricated token-expiry warnings, OOM errors, and disk-full alerts designed to make AI-assisted analysis tools abort before completing their scan. It also wraps functional code in CBRN-themed docstrings to trigger safety refusals in LLMs. No existing scanner detects this anti-analysis evasion technique.

Where each tool fits

Snyk Agent Scan (formerly Invariant Labs' mcp-scan) is the closest competitor in the AI agent security space. It scans MCP server tool descriptions for prompt injection and tool poisoning, and inspects agent skills for malware payloads. However, it does not scan dependency source code, AI model files, CI/CD workflows, or ANSI-hidden content. It focuses on the agent configuration layer, not the supply chain.

Socket.dev pioneered slopsquatting detection and monitors package registries for behavioral anomalies (install scripts, obfuscated code, credential access). It does not scan source code for prompt injection, AI model files, MCP configurations, or CI/CD workflows.

Semgrep has 27 AI security rules for application-level prompt injection (e.g., unsanitized user input passed to LLM APIs) and 122 Pro rules for agent skill patterns. These target code you write, not code in your dependencies. Semgrep does not scan AI model files, detect slopsquatting, or verify SHA/version pin integrity.

Trivy and Grype are pure CVE-matching SCA scanners. They have no AI-specific detection capabilities. Trivy has an open feature request for OCI-format AI model scanning but has not shipped it. Notably, Trivy itself was compromised in a supply chain attack in March 2026, and its VS Code extension was weaponized with prompt injection payloads that hijacked developers' AI coding agents.

What depfence covers

depfence was built specifically for the AI era of software supply chain security. It combines traditional SCA (CVE matching via OSV, EPSS, KEV) with 10 AI-specific attack classes that no other single tool addresses:

  • Prompt injection in dependency source — 30+ patterns across comments, docstrings, string literals, package.json fields
  • Anti-analysis evasion — Gaslight-class fake system messages, CBRN refusal-trigger shields, legal/regulatory threats, classification markings
  • ANSI escape hiding — invisible text (SGR 8), cursor manipulation, screen clears, bidirectional overrides, zero-width characters, Cyrillic/Latin homoglyphs
  • Slopsquatting — detects packages matching known LLM hallucination patterns
  • MCP server auditing — tool poisoning, shadowing, rug-pull detection, credential leak scanning, fingerprinting
  • AI model file threats — pickle deserialization RCE, GGUF chat template SSTI, ONNX custom ops, TFLite delegate abuse
  • Fabricated SHA/version pins — resolves GitHub Action SHAs and package versions against registries; catches LLM-hallucinated pins
  • CI/CD workflow attacks — Cordyceps-class workflow_run privilege escalation, issue_comment TOCTOU, AI triage bot injection
  • Agent skill attacks — external instruction fetch, domain spoofing, deferred payloads
  • AI-BOM generation — AI Bill of Materials in CycloneDX format for model supply chain transparency

Complementary, not competitive

depfence is not a replacement for Snyk, Trivy, or Grype in their core domain of CVE matching and license compliance. It is designed to fill the AI-specific gap that those tools don't address. The recommended deployment is depfence alongside your existing SCA tool: Trivy or Grype for CVE coverage, depfence for AI-era threats.

For teams already using Snyk Agent Scan for MCP security, depfence extends coverage to the dependency source code, CI/CD workflows, and AI model files that Agent Scan doesn't inspect.

Tool Profiles

Snyk Agent Scan

Focus: MCP server and agent skill security.
Strengths: 15+ risk categories for MCP tool descriptions. Auto-discovers local agent configs (Claude, Cursor, Windsurf, Gemini CLI). Detects tool poisoning, shadowing, toxic flows, malware payloads in skills. Published ToxicSkills study scanning 3,984 agent skills, finding 36.8% had security flaws.
Gaps: Does not scan dependency source code, AI model files, CI/CD workflows, or ANSI-hidden content. No slopsquatting or fabricated-pin detection. No SBOM/AI-BOM generation.

Socket.dev

Focus: Package registry behavioral monitoring and supply chain anomaly detection.
Strengths: Real-time slopsquatting detection via registry monitoring. Behavioral analysis (install scripts, obfuscated code, credential access). GitHub app and browser extension for real-time alerts. Flagship research: 205,000 hallucinated package names across 576K AI code samples.
Gaps: Does not scan source code for prompt injection. No AI model file scanning. No MCP, CI/CD, or agent skill analysis. No ANSI hiding detection.

Semgrep

Focus: Static analysis rules for application code.
Strengths: 27 AI security rules for application-level prompt injection. 122 Pro rules for agent skill patterns. 186 Shadow AI rules for LLM usage detection. MCP server plugin for integration with AI coding tools. 5,000+ general security rules.
Gaps: Rules target code you write, not dependency source. No model file scanning. No slopsquatting or fabricated-pin detection. No ANSI or anti-analysis evasion detection. AI security rules require Pro tier.

Trivy

Focus: Container and filesystem CVE scanning.
Strengths: Mature CVE matching against NVD, GitHub Advisories, and distro feeds. Container image, filesystem, and IaC scanning. SBOM generation (CycloneDX, SPDX). Wide ecosystem support. Open-source, 24K+ GitHub stars.
Gaps: Zero AI-specific detection capabilities. No model file scanning (feature requested but not shipped). Itself compromised in a supply chain attack (March 2026). VS Code extension weaponized with prompt injection.

Grype

Focus: Lightweight CVE scanning for containers and filesystems.
Strengths: Fast, accurate CVE matching. EPSS and KEV integration. Clean CLI, easy CI integration. 12.4K GitHub stars, 50M+ downloads. Composite risk scoring (CVSS + EPSS + severity).
Gaps: Zero AI-specific detection capabilities. Pure CVE-matching tool with no awareness of prompt injection, model files, MCP, slopsquatting, or any AI-era attack class.
