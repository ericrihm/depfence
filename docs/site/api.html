Python API — basic usage

depfence exposes a public Python API via the depfence package. scan_directory is the canonical full-scan entry point used by the CLI.

python
import asyncio
from pathlib import Path
from depfence.core.engine import scan_directory

async def main():
    result = await scan_directory(
        Path(".").resolve(),
        fetch_metadata=False,  # fully offline
        enrich=False,
        profile="full",
    )

    print(f"Findings: {len(result.findings)}")
    for finding in result.findings:
        print(f"  [{finding.severity}] {finding.package} - {finding.title}")

asyncio.run(main())

Running a specific scanner directly

python
from depfence.scanners.slopsquat import SlopsquatScanner
from depfence.core.models import PackageId, PackageMeta
import asyncio

scanner = SlopsquatScanner()

packages = [
    PackageMeta(pkg=PackageId("pypi", "pytorch-cuda-nightly", "2.0.0")),
    PackageMeta(pkg=PackageId("pypi", "langchian", "0.1.0")),
]

findings = asyncio.run(scanner.scan(packages))
for f in findings:
    print(f.title, f.severity, f.metadata)

Accessing EPSS and KEV data

python
from depfence.core.epss import EpssClient
from depfence.core.kev import KevClient
import asyncio

async def main():
    epss = EpssClient()
    kev = KevClient()

    # EPSS probability for a CVE (0.0 to 1.0)
    score = await epss.get_score("CVE-2024-3094")
    print(f"EPSS: {score.probability:.4f} ({score.percentile:.1f}th percentile)")

    # Check if CVE is in CISA KEV
    is_kev = await kev.is_known_exploited("CVE-2024-3094")
    print(f"In KEV: {is_kev}")

asyncio.run(main())

Data models

PackageMeta

python
from dataclasses import dataclass, field

@dataclass(frozen=True)
class PackageId:
    ecosystem: str
    name: str
    version: str | None = None

@dataclass
class PackageMeta:
    pkg: PackageId
    description: str = ""
    homepage: str = ""
    repository: str = ""
    license: str = ""
    has_install_scripts: bool = False

Finding

python
@dataclass
class Finding:
    finding_type: FindingType
    severity: Severity              # critical | high | medium | low | info
    package: PackageId
    title: str
    detail: str
    cve: str | None = None
    cwe: str | None = None
    fix_version: str | None = None
    references: list[str] = field(default_factory=list)
    confidence: float = 1.0
    metadata: dict = field(default_factory=dict)

CycloneDX SBOM format

depfence generates CycloneDX 1.7 SBOMs by default, with explicit 1.5 compatibility output.

bash
depfence sbom . -o sbom.cyclonedx.json
depfence sbom . --cyclonedx-version 1.5 -o sbom-compat.json
depfence sbom-diff v1-sbom.json v2-sbom.json          # diff two SBOMs

Writing a scanner plugin

Normal CLI execution loads shipped scanners only. In 0.8, an embedding application must explicitly enable third-party discovery and approve each plugin fingerprint through the Python API.

python
# mypackage/scanners.py
from depfence.core.models import Finding, FindingType, PackageMeta, Severity

SUSPICIOUS_TLDS = [".ru", ".cn", ".xyz"]

class TldScanner:
    name = "tld_scanner"
    ecosystems = ["npm", "pypi"]    # or ["*"] for all

    async def scan(self, packages: list[PackageMeta]) -> list[Finding]:
        findings = []
        for pkg in packages:
            homepage = pkg.homepage
            for tld in SUSPICIOUS_TLDS:
                if homepage.endswith(tld):
                    findings.append(Finding(
                        finding_type=FindingType.BEHAVIORAL,
                        severity=Severity.MEDIUM,
                        package=pkg.pkg,
                        title=f"Suspicious homepage TLD: {tld}",
                        detail=f"Package homepage uses {tld}: {homepage}",
                        metadata={"scanner": self.name},
                    ))
        return findings

Registering a plugin

Register your scanner in pyproject.toml using the depfence.scanners entry point group.

toml
[project.entry-points."depfence.scanners"]
tld_scanner = "mypackage.scanners:TldScanner"
python
from depfence.core.registry import PluginRegistry, plugin_fingerprint

identity = "depfence.scanners:tld_scanner:mypackage.scanners:TldScanner"
registry = PluginRegistry(
    enable_third_party=True,
    trusted_plugin_fingerprints={plugin_fingerprint(identity)},
)
registry.discover()
assert "tld_scanner" in registry.scanners
Path plugins: Pass a directory via plugin_paths (or set DEPFENCE_PLUGIN_PATH) only with enable_third_party=True, and approve plugin_fingerprint(Path("/absolute/plugin.py")). Unapproved or changed files are not imported.

Webhook / event hooks

Configure depfence to POST structured JSON events to a webhook URL when findings are produced.

yaml
# depfence.yml
webhook:
  url: https://your-service.example.com/depfence/events
  on:
    - finding.critical
    - finding.high
    - scan.complete
  headers:
    Authorization: "Bearer ${WEBHOOK_TOKEN}"
json
{
  "event": "finding.critical",
  "timestamp": "2025-05-01T12:00:00Z",
  "project": "my-app",
  "finding": {
    "id": "DF-SLOP-001",
    "title": "Slopsquatting - pytorch-cuda-nightly",
    "severity": "CRITICAL",
    "scanner": "slopsquat",
    "package": "pytorch-cuda-nightly",
    "version": "2.0.0"
  }
}

Event bus integration

depfence can emit finding events to any HTTP event bus or webhook endpoint for automated triage, alerting, and cross-repo security posture tracking.

yaml
# depfence.yml
integrations:
  eventbus:
    enabled: true
    url: ${DEPFENCE_EVENT_BUS_URL}
    auth_header: "Bearer ${DEPFENCE_EVENT_BUS_TOKEN}"
    emit_on:
      - finding.critical
      - scan.complete
    tags:
      project: my-app
      env: production
json — event envelope
{
  "source": "depfence",
  "source_version": "0.8.0",
  "event_type": "security.finding",
  "timestamp": "2025-05-01T12:00:00Z",
  "payload": {
    "finding": { "...": "..." },
    "project_tags": { "project": "my-app", "env": "production" },
    "scan_id": "scan-uuid-here"
  }
}
